# M4.8 — bounded UTF-8 TEXT и compositor replay

Дата: 17.10.2026. Experimental protocol1 расширен optional TEXT=9 / QUERY=10;
wire sizes исходных запросов/событий/rect не изменены, старые ops совместимы.
Это не Workshop ABI4 target и не полный Unicode/font engine.

## Контракт и защита

QUERY с нулевыми аргументами возвращает RECT=1 и TEXT=2 только при наличии
trusted text sink. TEXT привязан к delivered DRAW token, принимает 24-byte
packet с x/y, foreground/background и offset/length UTF-8. Нативных указателей
в wire нет. Private user page walks проверяются для packet и string отдельно.

Полный snapshot до любых effects; строка 1..127 bytes без NUL на wire,
внутри ядра zero-terminated. Проверяются continuation bytes, overlong, surrogate,
truncation, >U+10FFFF, NUL и ASCII control. Invalid/quota/fault не расходуют
бюджет и не вызывают sink. До 1024 text bytes и 64 общих draw-команд за DRAW;
TEXT расходует одну команду. Int64 bounds отсекают fully offscreen текст до
передачи существующему clipped font renderer. Цвет 24-bit; 0xffffffff bg —
transparent. Сервис принимает Unicode scalar; отображение ограничено CP866 font.

GUI хранит kernel-owned ordered cache rect/text и воспроизводит его только
в window paint pass, после возврата из CPL3. User string не перечитывается
при repaint/cover/uncover. Shared kernel function-pointer table не выдаётся.
Добавлены comments, прямо называющие legacy ABI2/3 ring0, а не security boundary.
