## RED и область

255 UTF-16 units. Чтение выходило за границы заявленного key, а сборка имени

`build/autonomous/m611-ntfs-index-red.log`. Исправленная функция возвращает

## Границы после исправления

Index-entry decoder получает фактический остаток node buffer. До dereference
FILE_NAME проверяются entry/key sizes, exact `66 + 2*n` key length, 8-byte
entry length/alignment, допустимые flags, namespace, длина и UTF-16 sequence.
Last-entry sentinel должен иметь key length zero и согласованный размер.
Unpaired surrogate, embedded NUL или имя, не представимое полностью в
`VFS_MAX_NAME`, даёт error; имя не превращается в другое через усечение.
Корректные supplementary characters конвертируются в четыре UTF-8 байта.

$INDEX_ROOT entries_offset/end и INDX node offsets проверяются относительно
value/block до сложения/итерации. Каждый node обязан завершаться sentinel;
повреждённый хвост не становится пустым EOF. Non-resident index allocation
должен иметь block-multiple length, размер не превосходит объём тома по
кластерам, каждый блок читается целиком с USA/fixup. Короткий read, bad
signature/fixup и bad node возвращает listing error, а не partial EOF.
Поскольку lookup останавливается при найденном индексе, коррозия **после**
найденной строки проявится при следующем запросе; общий File Manager loader
discard-ит уже собранную панель при последующей ошибке.

Attribute walker проверяет first-attribute offset, полные header/attribute
sizes, resident/nonresident minimums и end marker. Resident value проверяет
value offset+length внутри owning MFT record до построения pointer. Attribute
list entry lengths/reference reads проверяются; отказ чтения extension
record остаётся ошибкой.

Runlist поддерживает текущий 32-битный предел: length/offset поля >4 bytes,
обрыв, нулевая длина, overflow VCN/LCN, отрицательный LCN и отсутствие
terminator отвергаются целиком (не используется частичный prefix). Boot
record negative exponents проверены до shift; принимаются только мощности,
которые помещаются в статические MFT/index buffers и I/O alignment.
USA offset/count и sector tails сверяются с размером record/block.

## Что это НЕ доказывает

Виртуальный NTFS образ с реальным созданием файлов в QEMU/mtools в этой среде
не собран; fixture synthetic. Hosted CI не запускался. Поэтому нет claims о
полной совместимости с реальными NTFS версиями, fragmented/non-resident
$ATTRIBUTE_LIST, index bitmap/large tree, sparse/compressed/encrypted files,
full 64-bit LCN/VCN, прочих sector geometries или hostile image qualification.
Текущий runlist parser ограничен 32-bit полями и фиксированными arrays.
NTFS остаётся read-only. Нет разрешения physical disks/hotplug или публикации.
FPU/TT/multiwriter остаются OPEN.
