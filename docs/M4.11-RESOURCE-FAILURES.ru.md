# M4.11 — fail-closed compiler adapter и resource regressions

17.10.2026. Продолжение изолированного native target; не hardware qualification.

User-only MCC adapter теперь прекращает приложение при отказе DRAW/TEXT/STATUS
(exit values 31/32/33), а не молча показывает неполный результат при исчерпании
quota. Ошибка включает reason/vector/exit value. Предел busy app — ровно 25
последовательных 2-tick quantum yields; на 25-м снимается с reason=KILLED.
Пользовательские диски и default legacy profile не затронуты.

Реальные программы из source-only fixtures компилируются ВНУТРИ Мастерской:
- запись по kernel address 0x100000: #PF/vector14, приложение снято;
- 70 pixel calls: command quota → exit31;
- 10 строк по 127 bytes: text byte quota → exit32;
- бесконечный draw: 25 quantum yields → KILLED;
- heap 32760 payload / 32768 total: отказ следующего alloc, free/reuse PASS;
- 8 private files×1024: отказ 9-го, отказ oversized write без truncation,
  read clamp и reuse после delete PASS;
- глобальный verify.c недоступен через private file_exists;
- после каждого теста PMM used_frames совпадает с baseline, GUI отвечает;
  private filenames отсутствуют в глобальном KvFS до legacy relaunch.

`abi4-3f5a5deb` exit0: BIOS32/UEFI64 PASS. ASan/UBSan service/image/address-space,
legacy267+267, isolated20+20 и 40000+40000 isolated compiler mutations PASS;
NORMAL release build PASS. Логи build/autonomous/m411-{host,native,release}.log.
JSON build/isolated-workshop/{i386,x64}/result.json.

Первый расширенный harness упёрся в общий RAMFS 32 entries при создании ещё
одного legacy файла. Исправлен тест: повторно используется уже существующее
имя; RAMFS лимит не увеличивался, guest policy не ослаблялась.
