# M4.10 — opt-in ABI4 target в Мастерской

Дата: 17.10.2026. Software checkpoint; не полный roadmap и не hardware qualification.

Мастерская сама компилирует ограниченный C в format2/API4. Переключатель
ABI3/kernel ↔ ABI4/CPL3 доступен мышью; default остаётся ABI3. Подключён
prelinked user-only adapter: его API3-shaped table содержит только user-code
addresses, не kernel pointers. Никакой host compiler не вызывается при сборке
исходника внутри ОС. GCC нужен при сборке самого образа ОС/adapter.

Сохранены source 16000, code 24000, data 8000 и legacy output 32768 budgets;
новому target выделен bounded output 49152 для дополнительного adapter text.
Программа RX у 0xe00000, adapter RX с 0xe06000, program data RW с 0xe08000,
adapter state/32 KiB heap в zero BSS с 0xe0b000. Обычный strict ABI4 loader,
без специального ring0 fallback. Статические/link-time проверки layout.

В этом profile доступны bounded rect/text, private status, hz/lang/ticks,
user-only heap/strings/format, private RAM file operations (8×1024).
line/clock/beep/file_list/log явно отвергаются компилятором; это не полная
совместимость со всеми возможностями legacy API. Draw/text сохраняют quotas
protocol1. FPU/float, TLS, persistent grants и SMP отсутствуют.
