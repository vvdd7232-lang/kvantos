# M4.3 — настоящий CPL3 diagnostic harness

Реализованы i386 iretd / x64 iretq transitions, private CR3/user stack и отдельный
8KiB kernel entry stack через TSS. Возврат восстанавливает исходные CR3/TSS/SS,
callee-saved registers и flags. User faults ловятся по CPL frame; kernel faults
в syscall не маскируются под fault приложения.

Команда `isotest` выполняет **только встроенные неизменяемые bytecode fixtures**:
не загружает произвольный `.kapp`, не меняет default ABI2/3 и не обращается к дискам.
Реальная CPU проверка BIOS32/UEFI64: exit, kernel/null/guard/RX write, kernel read,
CLI/OUT/HLT/MOV-CR3, UD2/divide-zero, stack overflow, бесконечный цикл, ограниченный
copy syscall и отрицательные wire/upper-half/readonly/overflow cases.
x64 дополнительно NX-data и noncanonical jump. Проверены CPL3 #PF error bits
и адреса, исходный kernel canary, восстановление CR3 и число PMM frames.

Native smoke трижды выполняет полный suite на каждом ядре, затем вызывает help
и ждёт новый shell prompt. Основные/расширенные M4.3 suites PASS; последующий
M4.4 suite расширяет те же fixtures реальными event/draw/private-RAM syscalls.
Это не приёмка всех arbitrary applications: public ABI4 loader/GUI/SDK ещё OPEN.
Первый harness синхронный с bounded timer kill; preempt/resume + kernel peers —
следующий M4.5 increment, не выдаётся за выполненный этим документом.
