# M4.4 — bounded services: проверенный increment

Дата: 17.10.2026. Код ядра `3ce7480`, адресные пространства `153d556`,
предыдущая интеграция/контракт `5036056`. Это не обещание полной POSIX/API3-совместимости.

- Запрос 40 байт, версия 1, generation, event token; snapshot до обработки.
- Событие 48 байт: DRAW/KEY/CLICK/TICK/CLOSE; delta не более 250 ms.
- Рисование: команды 24 байта, fill/outline, до 32 за запрос и 64 за событие.
  Полная проверка batch до sink, int64 clipping, canvas до 4096×4096,
  цвет 24 бита. Нативных указателей в wire-протоколе нет.
- Приватный RAM namespace: 8 файлов по 1024 байта, 8 handles, права R/W,
  CREATE/TRUNC, generation и невозобновляемые cookies. Имя — bounded ASCII.
  Это не RAMFS/KvFS/FAT grant; диски, устройства и kernel pointers не выдаются.
- Копирование проверяет реальные private page walks и права, не только длину.

## Выполненные проверки

`make -C tests/mcc CC=gcc-12 user-service`: Werror, ASan/UBSan,
детерминированные проверки и 20000 mutation requests для каждой архитектуры.
Нативный CPL3-suite: BIOS32 и UEFI64, по 3 запуска; среди CPU fixtures —
`event-wire`, `draw-clipped`, `RAM-capabilities`, `service-generation`,
`stale-handle`, `service-flags`. PASS, ресурсы освобождены.
Исходные proof: `build/autonomous/m44-proof/{i386,x64}.json`.

Сам по себе этот этап не включал публичный загрузчик или оконное приложение.
Последующая интеграция format2/ABI4 описана отдельно в M4.6; старые ABI2/3
остаются доверенным ring0-кодом.
