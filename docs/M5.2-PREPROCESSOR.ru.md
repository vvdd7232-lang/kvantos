# M5.2 — ограниченные объектные #define

Реализовано в kernel/mcc_pp.h; это не полный CPP. Примеры:

```c
#define COUNT N
#define N 4
#define COLOR (2+3)
void draw(void){int a[COUNT];a[0]=COLOR;clear(a[0]);}
```

- Object-like подстановка выполняется по preprocessing tokens, до двух проходов
  парсера. В строках/символах/комментариях и частях имён/чисел замены нет.
  Скобки автоматически не добавляются: `#define X 1+3`, `2*X` дают 5, как в C.
- Определения действуют от места объявления. Имена в body раскрываются при
  использовании, а не при определении. Пустая подстановка разрешена.
- Исходные переводы строк сохраняются, включая комментарии и строки директив;
  диагностическая строка относится к исходнику, а не расширенному буферу.
- BSS workspace: максимум 32 макроса, 47 байт имени, 255 байт body, 8 уровней
  раскрытия, 32000 байт результата, 64000 шагов. Исходный лимит остаётся 16000.
  Рекурсия, переполнение, ошибка директивы → size=0/output нетронут.
- Пока нет function-like macros, redefinition/undef, #/##, line continuation,
  multiline comments внутри директив, conditional compilation и predefined
  macros. Эти формы дают явную ошибку, а не молчаливое игнорирование.
- Строки с `#define` должны начинаться с директивы после whitespace/comments.
  Это не механизм доступа к хостовым заголовкам или дискам.

Host/Unicorn: 201 checks на target; ASan/UBSan 40000 mutations на target PASS.
Native Workshop smoke BIOS32/UEFI64 завершился PASS (source с macro names,
chained expansion и macro array extents собран/исполнен внутри ОС). Далее без паузы — structs/typedef, затем M4.2.
