# M5.3 — структуры и typedef в ограниченном native C

Реализация: kernel/mcc_types.h + native backend в mcc.c. Не полный ISO C.

```c
#define N 2
typedef struct Item {char label[5];int value;int *link;} Item;
typedef Item *IP;
Item saved;
void draw(void){
    Item a[N];IP p=a;++p;
    p->value=42;p->link=&p->value;
    saved.value=*p->link;
    clear(saved.value);
}
```

Поддержаны named/anonymous struct definitions, forward tags, self pointers,
вложенные **объекты ранее объявленных типов**, массивы объектов/полей, `.`/`->`,
указатели/индексирование/арифметика со stride структуры, sizeof(type/object/field).
Top-level typedef aliases для object/pointer types, в том числе `typedef struct`.
Функции принимают/возвращают **указатели**, не структуры по значению.
Глобальные структуры обнулены; локальные не инициализированы.

Layout: char size/align=1, int=4/4, pointers=4/4 (i386) или 8/8 (x64), member
alignment, tail padding и вложенный aggregate alignment. Размер/stride не обязан
быть степенью двойки: backend использует умножение/деление, а не ошибочный shift.
INC/DEC больших struct pointers не обрезает stride до imm8. Старый void-pointer
arithmetic extension (stride4) сохранён; арифметика incomplete struct запрещена.

Пределы: 32 tags, 256 fields суммарно, 32 typedef aliases, размер структуры до
8000 байт, прежние source/code/data/local-stack budgets. Workspace в BSS.
Два прохода воспроизводят layout; конфликт/лимит → size=0/output untouched.
Namespace плоский: нет local typedef/struct definitions или shadowing aliases.
Нельзя struct by-value assignment/initializer/argument/return, nested inline type
definitions, unions/enums, bitfields, packed layout, casts, array/function typedef.
Полная C type compatibility/scoping и bounds checking по-прежнему не заявлены.

Unicorn: 267 checks на target, включая независимый ctypes layout oracle,
raw pointer/member offsets, nested alignment, forward/self links, stride12/136,
pointer INC/DEC, sizeof без исполнения и отрицательные cases/atomic failure.
ASan/UBSan: по 40000 mutations с struct/typedef seeds PASS.
NORMAL release PASS. Native Workshop BIOS32/UEFI64 PASS: structs/typedef/member arrays/stride,
макросы и sizeof действительно скомпилированы и исполнены внутри ОС. Следом выполняется M4.2 — адресные пространства, не новый дизайн.
