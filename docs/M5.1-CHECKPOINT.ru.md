# M5.1 — ограниченные массивы и sizeof

17.10.2026, feature/storage-m3; development checkpoint, не опубликованный релиз.

## Изменения

- `kernel/mcc.c`: одномерные local/global массивы int/char/pointers, literal extent,
  native-width pointer decay и существующее индексирование. Отдельно хранится
  размер целого массива, чтобы sizeof не путал объект с decayed pointer.
- Allocation проверяется до умножения. Прежние CODE_MAX=24000, DATA_MAX=8000,
  LOCAL_MAX=128 и local stack 512/1024 bytes не повышены; массив занимает один
  local record, но **полный** объём стека, включая выравнивание.
- sizeof(type/expression/string) анализирует operand, затем откатывает emission
  code/data/relocations целиком. Вызовы/записи/инкременты не выполняются.
- Сохраняются format1, ABI3, int32 и native pointers32/64; ABI2 loader не изменён.
- RU/EN Workshop guides синхронизированы. M4 пока только design contract.

## Проверено

- Unicorn i386: 151 checks PASS; x86-64: 151 checks PASS, включая stack >4GiB,
  native pointer arrays, padding/canaries/decay/calls/zero globals, sizeof
  side effects/null dereference/string relocation rollback, negative cases и
  failure atomicity (output нетронут, size=0).
- ASan/UBSan: по 40000 детерминированных мутаций на target, с новыми array/sizeof
  seeds; PASS. Non-PIE используется для disposable host sanitizer executables.
- NORMAL `make -j2 CC=gcc-12 release`: PASS, 11 SDK apps на каждой архитектуре.
- Native Workshop в QEMU BIOS32 и UEFI64: открыть source с KvFS, скомпилировать,
  запустить и проверить status `41:2:3:4:5` от local/global/pointer arrays,
  sizeof без побочных эффектов, старых pointer/heap/8-argument/format calls.
  Reboot/reopen, независимые редакторы, error-no-stale-output, RAM-only/RU: PASS.
- BIOS CD/floppy и UEFI boot smokes: PASS. Это программные, не physical tests.

## Граница

Без VLA, multidimensional arrays, array initializers, array parameters syntax,
целых array pointers, sizeof(type-array), constant-expression extents и runtime
bounds checks. Global scalar initializers по-прежнему только литералы.
Результат sizeof — **int**, не size_t; `sizeof(sizeof(int)) == 4` на обеих
архитектурах. Не ISO C; native apps всё ещё ring0, не изолированы.
