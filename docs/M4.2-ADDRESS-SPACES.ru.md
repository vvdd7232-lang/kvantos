# M4.2 — реализованные private address-space primitives

`kernel/user_space.c`, `include/user_space.h`; это код, не только проект.
Два формата page tables: i386 2-level и x64 4-level. Собственная private spine
до virtual arena 14–16MiB, заимствованные kernel mappings остаются supervisor.
Общий kernel root и чужие tables не изменяются/не освобождаются. User pages
выдаются свежими, обнуляются перед публикацией/освобождением; guard pages намеренно не отображаются.

Политика R/W/X запрещает RWX. x64 может применять NX при включённом NXE;
i386 classic non-PAE не имеет NX — это открытое ограничение, не скрытая защита.
copyin/out проверяют overflow и **весь** диапазон до побочных эффектов, реальный
page walk/U/S/RW/NX и соответствие физического frame ownership, не одни bounds.
Offline RX loader отделён от user copyout. Pin запрещает map/load/destroy;
unpin/destroy после освобождения idempotent. Caller сериализует lifetime;
allocator callbacks доверенные, fresh reserved frames, direct map <128MiB.

Host ASan/UBSan: независимый CPU-shaped walker, двухпроцессная изоляция,
changed U/S/RW/frame aliases, полный arena из 512 страниц, guards/overflow,
частичный copy отказ без изменения destination, OOM на каждом table allocation,
100 create/map/destroy cycles на architecture; PASS. Native CPL3 harness M4.3
использует те же primitives. Public KAPP loader/runtime ещё не переключены.
