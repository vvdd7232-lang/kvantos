# M4.9 — private status и readonly environment

Дата: 17.10.2026. Experimental ABI4 protocol1, без смены legacy defaults.

Добавлены optional capabilities STATUS=4 и INFO=8, ops STATUS=11/INFO=12.
STATUS принимает snapshot 0..95 UTF-8 bytes, использует те же строгие scalar/
control проверки; ошибка не меняет старую строку. Пустая строка очищает status.
INFO копирует 16 байт `{1,16,PIT hz,language}` через проверенный writable walk.
Metadata обновляются в kernel event pump. User copy изменяема только приложением,
а исходное состояние ядра недоступно для записи. RTC/device/file grants нет.

GUI выбирает отдельную kernel-owned подпись `ABI4/CPL3` или `Trusted/kernel`;
private status не подменяет её. Новый SDK проверяет capabilities, hz/lang и status.

metadata bytes/destination/size; прежние 20000 requests + 5000 UTF-8 mutations
на архитектуру PASS. SDK и NORMAL release exit 0.
