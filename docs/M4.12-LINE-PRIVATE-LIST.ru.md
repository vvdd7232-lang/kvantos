# M4.12 — LINE и private LIST

17.10.2026. Experimental ABI4 protocol1; legacy defaults сохранены.

LINE=13 принимает 24-byte snapshot `{x0,y0,x1,y1,color,reserved=0}`.
Endpoint coordinates — signed16 range [-32768,32767], canvas≤4096²;
integer Cohen–Sutherland clipping ограничен 8 шагами. Произведения clipping
вмещаются в unsigned32; нет signed overflow и i386 64-bit division helpers.
Malformed/quota/phase failures атомарны; visible/offscreen возвращают 1/0,
расходуют одну общую draw quota. Sink получает только bounded client coordinates;
GUI сохраняет ordered snapshot и вызывает clipped renderer в paint pass.
Capability LINE=16 выдаётся только при наличии trusted sink.

LIST=14: `a=index,b=name40 offset,c=size4 offset,d=0`, token=0.
Перечисляет ТОЛЬКО used nodes приватного namespace; не global RAMFS/KvFS.
Оба назначения полностью preflighted до записи; overlap отвергается.
0=успех, MISSING=-9=конец. Capability LIST=32. MCC adapter копирует ответы из
собственных user-stack buffers, поддерживает nullable legacy-shaped arguments.
Из запретов isolated compiler удалены line/file_list; clock/beep/log пока запрещены.

Werror/ASan/UBSan: fixed clipping/reversed/degenerate/extreme/phase/quota cases,
10000 случайных signed16 segments на varied1..4096 canvases/arch, private LIST
и dual-output atomic failures PASS. Полные compiler267+267, target17+17,
40000+40000 isolated mutations и space/service/image suites PASS.
NORMAL release/SDK build PASS. Native процессы abi4-resource-isolation-6afcc1ca
и cpl3-sdk-bios32-uefi64-adcff258 exit0: Workshop/resource tests, CPU suite и SDK
GUI BIOS32/UEFI64 PASS. В native source-only proof проверяются visible clipped
line и имена/размеры private LIST вместе с прежним 41:2:ff:ok:A.

Ограничения: integer clipping, без antialiasing; endpoints вне signed16 rejected,
а не неограниченно rasterized. Private files не стали persistent grants.
Physical hardware/storage и FPU/float этим increment'ом не квалифицированы.
