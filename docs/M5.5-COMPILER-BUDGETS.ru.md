# M5.5 — review byte/table budgets MCC

Решение: **source16000 сохранён**, не увеличен автоматически до editor65535.
Редактор по-прежнему принимает/сохраняет длинные документы; >128 строк только
предупреждение. Source budget независим от строк и downstream ограничений.

Причины: после M5.4 headers и macro expansion разделяют PP_OUTPUT32000 и
PP_WORK64000; generated code/data ограничены layout изолированного target,
а compiler tables/8KiB kernel task stack не растут вместе с текстом. Увеличить
одну константу до64KiB — не значит обеспечить сборку64KiB программ. Текущий
increment фиксирует границы и проверяет их, не обещает новый ISO C уровень.

| Ресурс | Сохранённая граница |
|---|---|
| Original source | 16000 **байт**, включая UTF-8 комментарии/newlines |
| Preprocessor output/work | 32000 байт / 64000 шагов, header bodies charged |
| Macros | 32; имя47/body255/depth8 |
| Virtual headers | whitelist3, include-once/depth4/cycle detection |
| Tags/members/aliases | 32/256/32 |
| Symbols/locals/fixups | 256/128/1024; builtins занимают symbol slots |
| Args / expression depth / loops / breaks | 8 / 24 / 8 / 256 |
| Lexer tokens | 24000 на проход |
| Generated code / data | 24000 / 8000 байт |
| Local frame | 128×MCC_WORD =512 i386 /1024 x64 bytes |
| Legacy / isolated serialized output | 32768 /49152 bytes |

kvui.h занимает 13 macro slots, 3 aliases, 1 tag и 2 member slots. Поэтому
пределы пользовательских таблиц считаются **после** builtin costs, а не сверх
них. Globals aligned to MCC_WORD; низкоуровневый reserve_data сам не выравнивает
строки и metadata. Не объявляется bounds checking runtime массивов/полный C.

## Проверки

Новый `make -C tests/mcc CC=gcc-12 budgets`: 80 checks/arch, оба targets в каждом
binary, ASan/UBSan; production MCC включён напрямую, без test-only header registry.

- Source15999/16000 accepted,16001 rejected; NUL непосредственно перед PROT_NONE
  guard page. Короткие malformed directives/literals также стоят у guard page,
  чтобы чтение за NUL не скрывалось в запасе Python buffer.
- Macro/alias/tag/member/symbol/local/data/break tables: ровно допустимый объём
  принят, следующий элемент отказан с диагностикой. Builtin costs учтены.
- Emit/data/fixup/token/nesting guards на заполненных таблицах; compile после
  ошибок заново успешен. Ошибки public compile оставляют size0/output нетронутым.
- Source16000 с очень большим числом newlines принят; неизвестная функция на
  строке15001 диагностируется как15001. Независимого row cap не добавлено.
- UTF-8 comment у точной byte boundary принят; code points не подменяют bytes.

Production compiler/kernel/runtime не изменены относительно 8cf7b2c. Поэтому
native proof M4.13 BIOS32/UEFI64 остаётся применим к тем же исполняемым исходникам;
новый native boot не выдаётся за повторно выполненный именно ради test-only M5.5.
Лог: build/autonomous/m55-budgets-final.log. Full software baseline M4.13 PASS.

Дальнейшее увеличение source/table/expanded/code/stack budgets — отдельное
проверяемое изменение, не результат этого review. FPU/float/physical storage
qualification не закрыты; публикации нет.
