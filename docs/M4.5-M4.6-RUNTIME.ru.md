# M4.5 / M4.6 — продолжения CPL3 и opt-in SDK

Дата: 17.10.2026. **Экспериментальный software checkpoint, не стабильный релиз.**

## M4.5: ограниченный dispatcher

Полный interrupt frame сохраняется при quantum 2 PIT ticks. Перед возвратом
в GUI/peer восстанавливаются kernel CR3, TSS stack и CPU policy. Перед resume
проверяются CS/SS, executable IP, writable stack; flags фильтруются.
Внутренний diagnostic dispatcher допускает peer yield и kill suspended task.
Общий scheduler многопроцессных user tasks не реализован.

Для отсутствующего FPU context установлен CR0 TS|MP: x87/SIMD недоступны,
а не молча разделяют состояние ядра. SYSENTER_CS обнулён при SEP; на x64
EFER.SCE выключен на время исполнения. Policy возвращается до kernel peers.
IRQ entry i386 выполняет CLD; пользовательский DF сохраняется в continuation.
i386 TSS descriptor исправлен на available type 0x89. Новый публичный старт
использует zeroed frame (в отличие от старого лабораторного enter helper).

Нативный тест `tests/boot/user-isolation-smoke.py`: BIOS32 32 fixtures × 3,
UEFI64 37 × 3 = **207 PASS**. Проверены DF, x64 R12, EBP/stack, clock loop,
не менее четырёх resume slices, peer liveness, kill после трёх slices,
#NM, SYSENTER/SYSCALL fences, прежние защиты и cleanup. Процесс
`cpl3-df-fpu-0df04495` завершился exit 0. Proof сохранён отдельно:
`build/autonomous/m45-proof/{i386,x64}.json` (содержит исторический pre-loader label).

## M4.6: контейнер и жизненный цикл

`include/user_image.h`, `kernel/user_image.c`: strict format2 / API4,
заголовок 96 байт; flags строго 1 или 257 по архитектуре. Base 0x00e00000,
максимум payload 65536 байт, entry внутри text, данные page-aligned в VA,
16-byte aligned в файле; padding нулевой; длины, BSS, title NUL и protocol
проверяются до выделения ресурсов. Text RX, data/BSS RW, stack 4–64 KiB RW,
read-only bootstrap на offset 0x1e0000, свободный зазор перед stack.
i386 non-PAE **не имеет аппаратного NX**; x64 NX зависит от CPU capability.
Load/OOM transactional; ошибка format2 **или** API4 не ведёт к ring0 fallback.

Bootstrap 32 байта, версия 1, generation, canvas, architecture/NX. i386 cdecl
и x64 SysV entry, int80 offset/length requests. Private frames закреплены на
весь срок жизни. Очередь 8 событий, DRAW/TICK coalescing, TICK до 250 ms.
COMPLETE / empty WAIT завершают pump с сохранённым frame. После 25
последовательных quantum yields приложение снимается; отдельный fault не
завершает desktop. Fault diagnostics сбрасываются перед каждым pump.

Оконный мост **не рисует из syscall**: validated rectangles копируются в
kernel-owned cache (до 64 на DRAW token) и воспроизводятся только в paint
pass этого окна. Это необходимо, поскольку продолжение DRAW может завершиться
во время следующего tick/key pump, когда прежний clip/frame уже недействителен.
Первый GUI test выявил пустой canvas при успешных draw syscalls; cache/replay
устранил именно наблюдаемый дефект. Последующий тест выявил, что старый
`win_close` только удалял окно: добавлено освобождение KAPP и при крестике,
и при выходе из GUI. CLOSE best-effort, затем принудительный teardown:
services → unpin → zero/free frames; legacy callbacks сохраняют свой guard.

Legacy format1 header_size/code+BSS/title дополнительно ограничены.
**ABI2/3 по-прежнему ring0**, не становятся изолированными из-за нового loader.

## SDK и фактический public GUI proof

`make -C sdk/isolated CC=gcc-12` собирает отдельные boxes32/64.kapp.
Это opt-in freestanding SDK без libc/FPU, не замена 11 default apps.
Образец рисует 3 rectangles, обрабатывает события и читает обратно число 42
из своего private.txt. Workshop/compiler по умолчанию всё ещё создаёт ABI3.

`tests/mcc/test_user_image.c`: Werror/ASan/UBSan, layout/overflow/arch/entry,
права/guards/BSS, все allocation-failure cuts тестового образа, 20000 mutations
на архитектуру; реальные packed SDK32/64 также прошли host validation.

`python3 tests/boot/isolated-app-smoke.py`, процесс
`abi4-gui-bios32-uefi64-e3b8ed46`, **exit 0**. Настоящие BIOS/i386 и UEFI/x64:

- Program Manager загружает SDK с disposable 16 MiB KvFS fixture;
- private file=42, click counter изменяется, зелёный rectangle виден в PPM;
- wrong-arch, x87, infinite loop, kernel write и malformed legacy header
  отвергаются/снимаются; desktop остаётся работоспособным;
- закрытие возвращает PMM used_frames к baseline;
- ABI2 prefix fixture и повторные ABI4↔ABI2 переходы без утечки private frames;
- Блокнот принимает текст после отказов; SHA256 исходного fixture disk неизменён.

Proof: `build/isolated-app/{i386,x64}/{result.json,isolated.ppm}`,
`build/autonomous/m46-gui-native.log`. ABI2 fixture — текущий calc с API field=2,
а не независимо собранный исторический binary. Инъекция тестовых файлов в
fixture image — **не** предлагаемая пользователю host-import feature.

## Следующие пункты, не выдаваемые за готовые

- Explicit legacy trust label в UI; дальнейшая CPU-policy/FSGSBASE проверка.
- Coherence долгоживущих private roots при новых supervisor/MMIO mappings.
- Дополнительные queued-DRAW/resize/GUI-exit и resource-abuse regressions.
- Компилятор Workshop ABI4, расширенные graphics/text services, capabilities
  для пользовательски выбранных файлов; это отдельные последующие increment'ы.
- FPU context и только затем float; SMP/multiple user processes/TLS не заявлены.
- Save64 historical cause, физические TT/USB/SATA/VBox остаются OPEN.

Новых tag/push/release/archive и обращений к физическим дискам не было.
