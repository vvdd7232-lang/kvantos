# KvantOS 3.1.2 — редакторы с управлением мышью

15 октября 2026 года. Обновление Блокнота, C-мастерской и навигации рабочего стола поверх 3.1.1. Отдельный релиз для **BIOS/i386 и UEFI/x86-64**; старые релизы не заменяются.

## Как начать

1. Загрузите **`kvantos.iso` из v3.1.2** и выполните `guimenu` в текстовой оболочке.
2. Один раз щёлкните **Блокнот** или **C-мастерскую** на рабочем столе либо выберите приложение в меню **КВАНТ** снизу слева.
3. В тексте щелчок ставит курсор, протяжка мышью выделяет. Кнопки **Копия / Вырезать / Вставить / Отмена / Всё** доступны без сочетаний клавиш.
4. В мастерской нажмите **Собрать** или **Запуск**, чтобы собрать готовый `hello.c` и запустить нативное приложение. Кнопка **Справка** открывает памятку с собственной кнопкой закрытия.
5. Закрывайте окна крестиком, переключайте панелью или меню. Выход в консоль: **КВАНТ → Выйти в консоль**.

Одиночные **G/B/E/T/Q/W** и другие буквенные команды рабочего стола убраны. Клавиатура остаётся для текста и необязательных редакторских сочетаний; **управление внутри игр сохранено**. Esc в редакторе отменяет диалог/выделение, а не закрывает окно или рабочий стол.

## Что изменилось

- **Редактирование мышью:** установка курсора, многострочное выделение, автопрокрутка при протяжке за край. Курсор, выделение и удаление UTF-8-текста учитывают границы символов.
- **Общий буфер обмена** между Блокнотом и мастерской, независимые документы и одношаговая отмена/повтор. Повторное нажатие «Отмена» возвращает отменённую правку.
- **Диалоги «Открыть» и «Сохранить как»:** списки файлов RAM/Диск (KvFS), прокрутка, поле имени с мышиным курсором, кнопки подтверждения и отмены. Вводить путь или нажимать Enter для открытия выбранного файла не обязательно.
- **Рабочие вертикальная и горизонтальная полосы:** перетаскивание ползунков, стрелки, прокрутка страниц; колесо мыши и Shift+колесо. Просмотр документа больше не возвращается к неподвижному текстовому курсору при перерисовке.
- **Защита несохранённого текста** при создании, открытии, закрытии и обоих способах выхода в консоль. Замена другого существующего файла и удаление требуют подтверждения.
- **Блокнот сохраняет в RAM и на смонтированный KvFS**, как и мастерская. Без диска RAM временна, о чём сообщает статус.
- **Без молчаливого обрезания:** предел 128 строк по 120 байт; превышение лимита при вставке, склейке или загрузке не уничтожает текущий документ. Двоичные файлы отвергаются.
- **Необязательная мышь с NumPad:** включается через меню КВАНТ или NumLock. 8/2/4/6 и диагонали — движение, 5 — щелчок, 0 — зажать, точка — отпустить, Shift — точно, Ctrl — быстро, +/- — скорость. По умолчанию выключена.

Сохранены dirty-rectangle renderer и кеш рабочего стола, нативные компиляторы i386/x86-64, `.c/.kapp`, RAM/KvFS, все 11 SDK-приложений на архитектуру и оба пути загрузки. Перестроено размещение элементов для экрана **640×480**.

## Проверки

Сборка GCC 12; проверки включены в workflow перед публикацией:

- 73 теста машинного кода на backend, по 40 000 мутаций компилятора под ASan/UBSan, атомарная RAMFS/OOM-проверка.
- Модель текста: выделение, UTF-8, отмена/повтор, границы и атомарность ошибок, 25 000 правок под ASan/UBSan.
- В QEMU на обоих ядрах: мышиные действия, общий буфер обмена, диалоги, сохранение/отмена/замена, пустые/двоичные/слишком длинные файлы, колесо и оба ползунка, автопрокрутка, список файлов, NumPad, русский интерфейс, защита выхода и 640×480.
- Реальная запись Блокнота на KvFS с проверкой содержимого диска после закрытия гостя.
- Полная сборка и запуск C-программы внутри гостя, независимость редакторов, нативный draw/click, ошибка без запуска старой сборки, чтение исходника с KvFS после полной перезагрузки, ABI/heap/восемь аргументов/вариативный format, русская сборка без диска.
- BIOS/UEFI CD, BIOS/UEFI USB, альтернативный direct ISO и нативный Maze 3D с клавиатурой и таймером.

Проверки выполняются с измеренными координатами гостя и ограниченным числом перемещений, без слепого повторного наведения мыши. Реальное оборудование отдельно не сертифицировано.

## Файлы и запуск

- **`kvantos.iso`** — рекомендуемый BIOS/UEFI ISO и гибридный образ для USB.
- **`kvantos-direct.iso`** — альтернативный BIOS/UEFI CD/DVD-образ без GRUB; не для прямой записи на USB.
- **`kvantos-3.1.2.tar.gz`** — полный комплект: оба ISO, дискета, ядра, EFI, ESP, пустой диск KvFS, приложения, документация и SHA256SUMS.
- **`kvantos-3.1.2-source.tar.gz`** — исходники; **`kvantos-3.1.2-SHA256SUMS.txt`** — контрольные суммы загрузок.

Распакуйте полный комплект. BIOS:

```sh
qemu-system-i386 -m 256 -boot d -cdrom kvantos.iso \
  -drive file=kvantos-disk.img,format=raw,if=ide
```

UEFI (OVMF, Secure Boot выключен):

```sh
cp /usr/share/OVMF/OVMF_VARS_4M.fd OVMF_VARS.fd
qemu-system-x86_64 -machine q35 -m 256 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=OVMF_VARS.fd \
  -cdrom kvantos.iso -boot d \
  -device piix3-ide,id=kvide \
  -drive file=kvantos-disk.img,format=raw,if=none,id=kvdata \
  -device ide-hd,bus=kvide.0,drive=kvdata
```

Для сохранения нужен поддерживаемый **IDE/ATA PIO**, не AHCI/SATA/NVMe: обычный `-drive if=ide` на q35 подключается через неподдерживаемый AHCI. Без диска приложения собираются и запускаются в RAM. `lang ru` переключает интерфейс на русский. В полном комплекте: `sha256sum -c SHA256SUMS`; для загрузок релиза: `sha256sum -c kvantos-3.1.2-SHA256SUMS.txt`.

## Ограничения

Экспериментальная ОС. Приложения работают в **ring 0 без полноценной изоляции** и могут повредить память или повесить систему. Мастерская реализует ограниченное подмножество C, не GCC/полный ISO C: нет препроцессора, структур, typedef, float, libc, объявлений массивов и полных проверок типов. Исходник можно переносить между архитектурами и пересобирать; готовый `.kapp` привязан к разрядности ядра. Буфер обмена внутренний, не общий с основной ОС компьютера; отмена одношаговая. Русская раскладка клавиатуры и прямая запись из редакторов в FAT32/NTFS в этот релиз не добавлялись.
