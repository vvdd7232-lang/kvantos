# KvantOS 3.1.1 — C-мастерская

14 октября 2026 года. Исправленный релиз после 3.1.0: **C-мастерская теперь действительно включена в образы обеих разрядностей**.

## Где открыть

1. Загрузите **новый `kvantos.iso` из релиза v3.1.1**, не образ 3.1.0.
2. В текстовой оболочке выполните `guimenu`.
3. Нажмите **B** или откройте значок **«C-мастерская» / C Workshop** на рабочем столе. При невысоком разрешении значки переходят во второй столбец.
4. Откроется готовый `hello.c`. **F5** — собрать, **F6** — пересобрать и запустить. Щелчок внутри окна программы перемещает квадрат: это нативный C-обработчик, не имитация.

## Что добавлено

- Встроенный редактор с независимым от блокнота документом, номерами строк, прокруткой, Home/End/Delete/Tab.
- Нативная компиляция ограниченного подмножества C **внутри самой ОС**, без GCC, сети и внешних инструментов.
- **i386 и x86-64:** компилятор создаёт `.kapp` под запущенное ядро. 64-битная версия использует 64-битные указатели, SysV-обработчики и корректно выровненные вызовы API, в том числе вариативные.
- **Ctrl+S** — сохранить исходник, **F2** — открыть по имени, **Ctrl+U** — очистить поле имени, **F1** — справка, **Ctrl+N** — вернуть шаблон.
- Исходник и приложение сохраняются в RAM, а при смонтированной KvFS — также на диск. После перезагрузки исходник открывается через F2. Без диска статус явно предупреждает о временном хранении.
- При ошибке компиляции показывается строка ошибки; F6 не запускает старую сборку вместо новой.
- Атомарная замена файлов RAMFS и безопасная обработка отсутствия свободного окна при запуске `.kapp`.

Подробное руководство: [sdk/WORKSHOP.ru.md](sdk/WORKSHOP.ru.md).

## Проверки

- **73 проверки исполнения машинного кода для каждого backend**, всего 146. В x86-64 тестах стек расположен выше 4 ГиБ; проверяются указатели, выравнивание SysV и сохранность регистров.
- **40 000 мутаций исходника для каждого backend**, всего 80 000, под ASan/UBSan. Проверены и ошибки сохранения RAMFS при нехватке памяти.
- В QEMU отдельно для BIOS/i386 и UEFI/x86-64: сборка, запуск, нативный щелчок, независимые редакторы, ошибочная программа, открытие и пересборка с KvFS после полного перезапуска, русская мастерская без диска.
- В обеих гостевых ОС дополнительно собрана и исполнена программа с локальными переменными, двойными указателями, выделением памяти, функцией с 8 аргументами и вариативным `format`.
- Сохраняются проверки BIOS/UEFI CD, BIOS/UEFI USB и Maze 3D из 3.1.0.

Для сборки использован GCC 12. Тесты входят в исходники и запускаются workflow релиза до публикации.

## Файлы и запуск

- **`kvantos.iso`** — рекомендуемый основной BIOS/UEFI ISO и образ для USB.
- **`kvantos-3.1.1.tar.gz`** — полный комплект: оба ISO, дискета, ядра, EFI, ESP, пустой диск KvFS, 11 SDK-приложений в каждой разрядности, документация и SHA256SUMS. Мастерская встроена в ядро, а не добавлена двенадцатым SDK-приложением.
- **`kvantos-direct.iso`** — альтернативный BIOS/UEFI CD/DVD-образ без GRUB; не для прямой записи на USB.
- **`kvantos-3.1.1-source.tar.gz`** — исходники; **`kvantos-3.1.1-SHA256SUMS.txt`** — контрольные суммы загрузок.

Распакуйте полный комплект и запустите BIOS-версию:

```sh
qemu-system-i386 -m 256 -boot d -cdrom kvantos.iso \
  -drive file=kvantos-disk.img,format=raw,if=ide
```

Для UEFI выберите 64-битную виртуальную машину с OVMF/EFI и отключённым Secure Boot. Например:

```sh
cp /usr/share/OVMF/OVMF_VARS_4M.fd OVMF_VARS.fd
qemu-system-x86_64 -machine q35 -m 256 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=OVMF_VARS.fd \
  -cdrom kvantos.iso -boot d \
  -device piix3-ide,id=kvide \
  -drive file=kvantos-disk.img,format=raw,if=none,id=kvdata \
  -device ide-hd,bus=kvide.0,drive=kvdata
```

`lang ru` переключает интерфейс на русский. `sha256sum -c SHA256SUMS` проверяет файлы полного комплекта.

## Ограничения

Это не полный ISO C и не GCC: нет препроцессора, структур, typedef, float, стандартной библиотеки, объявлений массивов и полных проверок типов. Старые SDK-примеры с `sys->...` требуют адаптации для мастерской. Исходник можно переносить между разрядностями и пересобирать; готовый `.kapp` привязан к разрядности ядра.

Система экспериментальная. Приложения работают в **ring 0 без полноценной изоляции**; ошибочные указатели и бесконечные циклы способны повредить память или повесить ОС. Перед установкой на реальный диск прочитайте INSTALL.ru.md и сохраните данные.
