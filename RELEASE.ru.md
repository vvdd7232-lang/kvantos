# KvantOS 3.1.3 — USB, GPT и предупреждение вместо лимита строк

16 октября 2026 года. Отдельный релиз для **BIOS/i386 и UEFI/x86-64**.
Старые теги и опубликованные файлы 3.1.2 не заменяются.

## Главное

* **Импорт с настоящего USB mass-storage:** кнопка «Импорт» в Блокноте и
  C-мастерской, выбор папок и файлов мышью, «Обновить», редактируемое локальное
  имя, подтверждение замены. Не требуется перенос через KvFS-образ на ПК.
* **USB 2.0/EHCI и USB UHCI**, FAT16/FAT32, разметка MBR, raw FAT и
  **GPT + FAT32**, в том числе служебный MSR перед разделом данных.
  GPT проверяется по CRC заголовка и таблицы, есть чтение резервной копии.
  Флешка не изменяется; форматирование и перевод GPT в MBR не нужны.
* **128 строк — только янтарное предупреждение.** Импорт, редактирование,
  выделение, clipboard, отмена/повтор и сохранение продолжают работать.
  Сотни строк собираются и запускаются, если соблюдены отдельные ограничения
  компилятора. Пятизначные номера получают расширенное поле.
* Документы хранятся упакованно; копируются только активные байты и индексы,
  ширина кэшируется вместо обхода всего текста на каждом кадре.
* Сохранены независимые редакторы, мышиный интерфейс 3.1.2, NumPad MouseKeys,
  RAM/KvFS, оба native-backend, 11 SDK-приложений на архитектуру и оба пути загрузки.

## Как пользоваться

1. Загрузитесь с нового `kvantos.iso`; в оболочке выполните `guimenu`.
2. В VirtualBox включите **USB 2.0 (OHCI + EHCI)** и захватите флешку в VM.
3. «C-мастерская → Импорт → Обновить → папка → файл → Импорт».
4. При необходимости измените локальное имя; «Сохранить / Собрать / Запуск».
5. После 128 строк можно продолжать: предупреждение не блокирует работу.

Импорт создаёт копию в RAM, **не сохраняет на диск автоматически**.
Сохранение идёт на смонтированный KvFS; без него RAM исчезнет при перезагрузке.
При смене ISO старая установленная копия ядра на HDD сама не обновится —
загрузитесь именно с нового ISO.

## Честные ограничения

* Входной файл и нормализованный текст редактора **меньше 64 КиБ**, до
  **120 байт в строке**. Отдельного лимита количества строк нет.
* Native-компилятор: **до 16000 байт исходника**, это отдельное ограничение,
  не строки. Больший текст редактируется/сохраняется; Build объясняет отказ,
  не меняя документ или undo. Компилятор остаётся ограниченным подмножеством C.
* UTF-8/BOM и CRLF поддержаны; Tab превращается в четыре пробела.
  UTF-16, двоичный ввод и переполнение отвергаются без обрезания текста.
* Поддержаны UHCI и high-speed EHCI root-порты, 512-байтные секторы и BOT.
  Отдельного OHCI-драйвера, xHCI/USB 3, хабов, split-транзакций и UAS нет.
  VirtualBox USB 1.1 — OHCI, не UHCI.
* GPT: только чтение, проверки границ/CRC, до 1024 записей, без ремонта;
  адресация текущего блочного слоя 32-битная. Прямое сохранение на FAT32 нет.
* Список каталога — до 128 подходящих элементов из первых 512 записей;
  это не ограничение числа строк документа.

Инструкции: [USB/FAT32](https://github.com/vvdd7232-lang/kvantos/blob/v3.1.3/USB-IMPORT.ru.md)
· [C-мастерская](https://github.com/vvdd7232-lang/kvantos/blob/v3.1.3/sdk/WORKSHOP.ru.md).

## Проверки

GCC 12; release-workflow проверяет до публикации:

* 73 проверки машинного кода/backend, 40000 sanitizer-мутаций/backend,
  RAMFS/OOM, текстовая модель с 25000 правок под ASan/UBSan.
* Полный байтовый пул, 65536 пустых строк, позиции, undo/redo, переполнение
  после раскрытия Tab и атомарность отказа. Максимум пустых строк следует
  из байтового бюджета, это не новый независимый строковый предел.
* GPT: 23 проверки CRC/резервных копий/границ, MBR/raw-регрессии, SHA-256
  исходных образов не изменяются.
* USB 2.0/EHCI с OHCI-компаньонами, GPT и MBR, оба ядра: папки, BOM/CRLF,
  импорт, смена имени, отмена, 12 сканирований, отключение/переподключение,
  запись на KvFS и полная перезагрузка.
* Исходник на 517 строк (512 комментариев плюс рабочее приложение): правка
  за строкой 128, мышиная отмена/повтор, native Build/Run, повторный запуск
  после открытия с KvFS. Текст >16000 байт разрешено править и сохранять,
  компилятор отказывает с объяснением, не меняя документ.
* Блокнот: UTF-8 на 2049 строк с повторным открытием после перезагрузки;
  10001 строка, правка/undo/сохранение, пятизначное поле номеров.
* Мышиные сценарии, clipboard, полосы/колесо, NumPad, русский интерфейс,
  640×480, защита несохранённых правок; desktop/Maze 3D, native ABI/heap.
* BIOS/UEFI CD, гибридный firmware USB boot и альтернативный direct ISO.

Проверки выполняются в **QEMU**, с измеренными координатами мыши.
Физическая флешка и сам VirtualBox здесь не проверялись.

## Файлы и запуск

- **`kvantos.iso`** — рекомендуемый BIOS/UEFI ISO и гибридный образ для USB.
- **`kvantos-direct.iso`** — альтернативный BIOS/UEFI CD/DVD-образ без GRUB; не для прямой записи на USB.
- **`kvantos-3.1.3.tar.gz`** — полный комплект: оба ISO, дискета, ядра, EFI, ESP, пустой диск KvFS, приложения, документация и SHA256SUMS.
- **`kvantos-3.1.3-source.tar.gz`** — исходники; **`kvantos-3.1.3-SHA256SUMS.txt`** — контрольные суммы загрузок.

Распакуйте полный комплект. BIOS:

```sh
qemu-system-i386 -m 256 -boot d -cdrom kvantos.iso \
  -drive file=kvantos-disk.img,format=raw,if=ide
```

UEFI (OVMF, Secure Boot выключен):

```sh
cp /usr/share/OVMF/OVMF_VARS_4M.fd OVMF_VARS.fd
qemu-system-x86_64 -machine q35 -m 256 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=OVMF_VARS.fd \
  -cdrom kvantos.iso -boot d \
  -device piix3-ide,id=kvide \
  -drive file=kvantos-disk.img,format=raw,if=none,id=kvdata \
  -device ide-hd,bus=kvide.0,drive=kvdata
```

Для сохранения нужен поддерживаемый **IDE/ATA PIO**, не AHCI/SATA/NVMe: обычный `-drive if=ide` на q35 подключается через неподдерживаемый AHCI. Без диска приложения собираются и запускаются в RAM. `lang ru` переключает интерфейс на русский. В полном комплекте: `sha256sum -c SHA256SUMS`; для загрузок релиза: `sha256sum -c kvantos-3.1.3-SHA256SUMS.txt`.

## Ограничения

Экспериментальная ОС. Приложения работают в **ring 0 без полноценной изоляции** и могут повредить память или повесить систему. Мастерская реализует ограниченное подмножество C, не GCC/полный ISO C: нет препроцессора, структур, typedef, float, libc, объявлений массивов и полных проверок типов. Исходник можно переносить между архитектурами и пересобирать; готовый `.kapp` привязан к разрядности ядра. Буфер обмена внутренний, не общий с основной ОС компьютера; отмена одношаговая. Русская раскладка клавиатуры и прямая запись из редакторов в FAT32/NTFS в этот релиз не добавлялись.
