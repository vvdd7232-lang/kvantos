# KvantOS 3.5.0 — procfs и shared GUI

26 октября 2026. Обновление **BIOS/i386** и **UEFI/x86-64**.
Опубликованные 3.4.0 и более ранние версии не изменяются.

## Что нового

- Read-only `/proc`: CPU, память PMM, uptime, ticks и сведения о задачах ядра.
  Работает через VFS, `cat /proc/meminfo`, `cat /proc/0/status`; сохраняется
  после rescan и не отнимает один из восьми слотов дисковых томов.
- Безопасное копирование метаданных задач под IRQ guard, ограниченный обход;
  устранено возможное зависание task_count на кольце DEAD-задач.
- Экспериментальный **CPL3 ABI4 protocol2**: два общих ARGB8888-буфера.
  Приложение заполняет back; после COMPLETE ядро делает его read-only front.
  Композитор читает те же физические страницы без пересылки пикселей в сообщениях.
- Подсчёт ссылок, защита aliases, очистка страниц при последнем освобождении,
  CPU alpha blending. Приложение не получает адресов или функций ядра.
- SDK-демо `pixels32.kapp` / `pixels64.kapp`: анимированные полупрозрачные пиксели;
  **Q** — выход, **F** — намеренная запись в front для проверки CPL3 page fault.
  Демо лежат в архиве `sdk/isolated/build/` и доступны отдельными файлами релиза;
  для запуска их нужно добавить в KvFS и открыть Program Manager.

## Ограничения и совместимость

Surface пока фиксирована **420×300**: без resize, dirty rectangles, GPU acceleration
и заявленного прироста FPS. При изменении окна поверхность обрезается, не растягивается.
Динамические модули ядра **не реализованы**.

`/proc/<id>` описывает kernel tasks, не POSIX-процессы. VFS пока не имеет
snapshot-on-open: для согласованного содержимого читайте весь файл одним read.
`ps`, `mem`, Monitor и ring3 file service ещё не переведены на `/proc`.
Старый `cat readme.txt`, trusted ABI2/3 и ABI4 protocol1 остаются совместимыми;
protocol2 включается явно в заголовке format2-приложения. Светлый «Бриз» сохранён.
Политика записи FAT/WAL и ограничения USB/AHCI/NTFS не менялись.

Реализация использует архитектурные идеи ToaruOS, но не включает её исходный код;
upstream имеет лицензию NCSA. Подробности: `docs/PROCFS-SHM-MODULES.ru.md`.

## Сокращённый релизный прогон

Публикация разрешена только после сборки, host ASan/UBSan-тестов, проверки образов,
BIOS/UEFI CD/USB boot, рабочего стола, `/proc`, CPL3 isolation, shared surfaces
(включая запрет записи в front и освобождение кадров) и совместимости protocol1.
Быстрые GPT/NTFS host-проверки также сохранены.

Из релизного критического пути убраны повторные длинные editor/Workshop,
AHCI/USB/WAL, Save As и GPT/MBR import-матрицы. Эти тесты не удалены из репозитория:
расширенные регрессии остаются в обычном build CI. Его полный результат не является
дополнительным условием публикации; меньший релизный набор проверяет именно этот тег.
Сокращение тестов не означает квалификацию реального оборудования или рост FPS.
