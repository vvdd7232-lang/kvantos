# KvantOS 3.1.0

14 октября 2026 года. Следующий релиз после 3.0.0 «Horizon».

## Что нового

- Перерисовка GUI по повреждённым прямоугольникам, кэш фона и значков, обновление только затронутых окон. Движение курсора больше не требует полной перерисовки рабочего стола.
- KvApp ABI 3: добавлен `delta_ms()`, сохранена совместимость с ABI 2. Таймер 500 Гц и расчёт движения по прошедшему времени для Pong, Snake, Life и Stars.
- **Maze 3D**: лабиринт от первого лица с целочисленным ray casting, затенением стен, коллизиями и мини-картой.
- **11 приложений в двух сборках** — для 32- и 64-битного ядра.
- Сохранены BIOS/GRUB, 64-битная UEFI-загрузка и альтернативный ISO без GRUB.

## Исправления перед выпуском

Проверка на современном OVMF обнаружила и позволила исправить ошибки UEFI-загрузки: перекрытие PE-заголовков секцией кода, отсутствие каталога релокаций и начальных значений BSS, неверные значения типов памяти EFI, поиск GOP, выделение памяти под ядро и доступность модулей после замены таблиц страниц. Вызов консоли EFI после `ExitBootServices` удалён.

В прямом BIOS-загрузчике исправлены адрес таблицы копирования, сохранение регистров, счётчик копирования, размещение стека и абсолютная адресация 2048-байтных CD-секторов. Меню GRUB обновлено до 3.1.0 и загружает весь набор из 11 приложений.

Основной ISO содержит загрузочную область GRUB и таблицу разделов с ESP для записи на USB; альтернативный `kvantos-direct.iso` предназначен для загрузки как CD/DVD-образ.

## Файлы

Полный комплект: **`kvantos-3.1.0.tar.gz`**.

- `kvantos.iso` — основной образ BIOS/UEFI; рекомендуется для виртуальных машин и USB.
- `kvantos-direct.iso` — альтернативный BIOS/UEFI CD/DVD-образ без GRUB.
- `kvantos-floppy.img` — 32-битная загрузочная дискета без встроенных приложений.
- `kvant.bin`, `kvant64.bin` — ядра обеих разрядностей.
- `kvantefi.efi`, `esp.img` — UEFI-загрузчик и раздел ESP.
- `apps/`, `apps64/` — по 11 приложений соответствующей разрядности.
- `kvantos-disk.img` — пустой диск KvFS на 16 МиБ для файлов; это не предустановленная ОС.
- `SHA256SUMS` — контрольные суммы образов, ядер, загрузчика и приложений.

Исходники этой сборки: `kvantos-3.1.0-source.tar.gz`. Отдельные файлы загрузки проверяются по `kvantos-3.1.0-SHA256SUMS.txt`.

## Запуск

Распакуйте комплект. Для BIOS:

```sh
qemu-system-i386 -m 256 -boot d -cdrom kvantos.iso \
  -drive file=kvantos-disk.img,format=raw,if=ide
```

Для UEFI используйте x86-64 и прошивку OVMF, например:

```sh
cp /usr/share/OVMF/OVMF_VARS_4M.fd OVMF_VARS.fd
qemu-system-x86_64 -machine q35 -m 256 \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=OVMF_VARS.fd \
  -cdrom kvantos.iso -boot d
```

В оболочке: `guimenu` — рабочий стол. Для русского интерфейса: `lang ru` или второй пункт меню GRUB при BIOS-загрузке. Для сохранения файлов подключите диск KvFS; файлы RAMFS исчезнут после выключения. Secure Boot не поддерживается: загрузчик не подписан.

Проверка файлов после распаковки:

```sh
sha256sum -c SHA256SUMS
```

## Сборка и проверки

Сборка релиза выполнена GCC 12.4, NASM, GNU binutils, GRUB и xorriso. GCC 14.2 в этой среде аварийно завершал оптимизацию 64-битного `kernel/main.c`; использована другая версия компилятора без изменения уровня оптимизации ядра.

```sh
make CC=gcc-12 release
python3 tests/boot/check-images.py
bash tests/boot/qemu-smoke.sh release/kvantos.iso
bash tests/boot/qemu-smoke.sh release/kvantos-direct.iso
BOOT_MEDIA=usb bash tests/boot/qemu-smoke.sh release/kvantos.iso
python3 tests/boot/gui-smoke.py
```

Оба ISO проверяются в QEMU через BIOS (Pentium, 128 МиБ) и UEFI (OVMF, 256 МиБ). Дополнительная GUI-проверка основного ISO проверяет загрузку всех 11 приложений, вход в рабочий стол, запуск Maze 3D и возврат в оболочку в обеих разрядностях.

## Ограничения

Экспериментальная ОС, не замена защищённой ОС для повседневной работы. Приложения работают без полноценной изоляции и могут повесить систему. NTFS доступна только для чтения. Перед установкой на реальный диск прочитайте `INSTALL.ru.md`: операции с диском могут уничтожить данные.

Этот релиз основан на актуальной ветке 3.1.0. Изменения C-мастерской из отдельной старой локальной 32-битной ветки сюда не переносились; мастерская не заявляется частью 3.1.0.
