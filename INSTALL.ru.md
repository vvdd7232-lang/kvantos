# Как загрузить своё приложение в KvantOS

*Английская версия: [INSTALL.md](INSTALL.md).*

Короткая инструкция для случая «у меня есть готовый файл `.kapp`».

---

## Способ 1: вложить в загрузочный образ (работает везде)

Подходит для **VMware**, VirtualBox и настоящего компьютера.
Жёсткий диск не нужен.

```bash
cd /home/user/kvantos
./sdk/addapp.sh /путь/к/snake.kapp
```

Скрипт положит приложение внутрь ISO, пропишет его в меню загрузчика
и пересоберёт образы. Получите:

```
release/kvantos.iso          <- подключить к машине
release/kvantos-floppy.img   <- запасной вариант
```

Дальше в VMware: **VM → Settings → CD/DVD → Use ISO image** и выбрать
`kvantos.iso`. Загрузиться.

В системе:

```
kvant:/$ ls              <- ваш .kapp уже здесь
kvant:/$ guimenu         <- графический режим
```

Нажать **G** (или значок «Программы») → ваша программа в списке →
щелчок по строке запускает её.

Несколько приложений сразу:

```bash
./sdk/addapp.sh snake.kapp tetris.kapp paint.kapp
```

## Способ 2: если нужен диск

Диск нужен **только** чтобы приложения могли сохранять свои файлы
(настройки, документы). Для запуска он не требуется.

### В VMware

1. **VM → Settings → Add → Hard Disk → SCSI?** — нет, выбрать **IDE**.
   Это важно: драйвер работает с IDE/ATA, диск SCSI система не увидит.
2. Размер — от 64 МБ, этого хватит с запасом.
3. Загрузиться и один раз разметить:

```
kvant:/$ disk            <- проверить, что диск виден
kvant:/$ format          <- разметить (СОТРЁТ всё на диске)
kvant:/$ df              <- убедиться, что ФС появилась
```

4. Перенести приложение из образа на диск:

```
kvant:/$ install snake.kapp
kvant:/$ apps
```

Теперь оно останется на диске и после перезагрузки.

### В QEMU

```bash
qemu-system-i386 -cdrom release/kvantos.iso \
                 -hda release/kvantos-disk.img -m 256
```

## Проверка, что всё правильно

Файл `.kapp` должен начинаться с подписи `KAPP`:

```bash
head -c 4 snake.kapp        # должно вывести: KAPP
```

Если подписи нет — файл не собран упаковщиком. Соберите так:

```bash
cd sdk
# положите исходник в sdk/apps/, затем
make
# готовое приложение появится в sdk/build/
```

## Частые вопросы

**Программы нет в списке.** Проверьте `ls` в оболочке: если файла там
нет, значит образ пересобрался без него — запустите `addapp.sh` заново
и убедитесь, что подключили **свежий** ISO, а не старый из истории.

**«Диск ATA не найден».** Это не ошибка: без диска приложения всё равно
запускаются из образа. Диск нужен только для сохранения файлов.
В VMware добавьте диск типа **IDE**, а не SCSI.

**Приложение не запускается, окно пишет причину.** Самое частое —
собрано под другую версию ABI: пересоберите с текущим `include/kvapp.h`.
Остальные причины перечислены в [APPS.md](APPS.md), раздел «Справочник ошибок».

**Как написать своё приложение.** Полное руководство —
[APPS.md](APPS.md). Там формат файла, все функции системы, примеры и
разбор ошибок. Готовые примеры с комментариями — в `sdk/apps/`:
часы, заметки и змейка.
